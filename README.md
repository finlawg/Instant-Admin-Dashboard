Instant Admin Dashboard
A clean PostgreSQL admin dashboard. It allows you to manage your databases from any browser without installation.
The website: https://instantdashboard.org

Features:

Connect and manage multiple PostgreSQL databases,
Browse, search, filter and edit table data,
SQL editor with query history,
CSV import/export,
Saved queries,
Table structure viewer,
Read-only mode,
Email verification.

See .env.example for required environment variables. Built with Node.js, Express, React, and PostgreSQL.
